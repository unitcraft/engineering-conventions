# Инженерные конвенции

Общие нормы для продуктового кода, не привязанные к проекту, стеку или движку. Проект ссылается на
нужную конвенцию из своих документов и ведёт у себя раздел отклонений: каждое отклонение записано,
с причиной и ценой.

| Конвенция | О чём |
|---|---|
| [api.md](api.md) | HTTP API: адреса, методы, тела, коды состояния, ошибки, коллекции, идемпотентность, повторы, потоки |
| [database.md](database.md) | реляционная база: время, даты, идентификаторы, перечисления, типы, обязательные колонки, удаление, идемпотентность, ретенция, ПДн, миграции |

Процесс работы — в соседних репозиториях
[ai-first-process](https://github.com/unitcraft/ai-first-process) и
[ai-dev-methodology](https://github.com/unitcraft/ai-dev-methodology).
